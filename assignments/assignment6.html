Data Pipeline & Architecture

I am using the free tier of hosting from render.com which may cause a one minute delay when fetching the API data.

This dashboard is powered by a .NET Minimal API proxy hosted using render.com's free tier to allow secure use of private API keys.

The C# worker utilizes HttpClient to chain four Riot endpoints. Fetching the global PUUID, The summoner profile icon and summoner level, extracting the Ranked Solo/Duo standings, and pulling the top five Champion Masteries. The worker normalizes this data into a single JSON payload, which is ingested to populate the UI dynamically below.
